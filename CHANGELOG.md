# Changelog

All notable changes to Unadly for Android are listed here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and versions follow
[Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-10-10

### Added

- Web browser built on Android WebView with ads blocked inside the engine: about 42,000 ad servers,
  blocked before requests leave the phone.
- Popup and popunder blocking: windows a page opens without a click are dropped.
- Home page with search (DuckDuckGo) and pinned sites with their icons.
- Pin the current site with the pin button.
- Ad counter showing how many ads were blocked on the current page.
- Back, forward and reload navigation.
- Opens web links from other apps (http/https intent filter).
- Real Unadly app icon (green shield with a white U).
- GitHub Actions CI workflow.
